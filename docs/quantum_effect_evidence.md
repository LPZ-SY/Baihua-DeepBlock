# Baihua 量子正向作用的证据边界

算法来源仓库 `LPZ-SY/QuantumRouteForge-current` 的 `main`（本次融合基于
commit `67dbd53f243d51db14b8ab7a461616096e140a0a`）报告了如下固定口径：

- 每个 DeepBlock 是同一个 8-bit 代理 QUBO，完整状态空间有 256 个状态；
- 在读取硬件 counts 之前，按能量秩预定义最低 10% 区域，即最低能的 26 个状态；
- 均匀随机进入该区域的精确概率为 `26 / 256 = 10.15625%`；
- Baihua 真机 counts 在该区域的平均概率质量为 `27.76%`；
- 因而真机相对均匀随机的富集倍数为 `27.76 / 10.16 = 2.73×`，绝对增加
  `17.60` 个百分点；
- 6/6 个独立 seed 的方向一致，双侧精确符号翻转检验 `p=0.03125`，按 seed
  bootstrap 的差值区间为 `[+11.05, +23.26]` 个百分点；
- 理想 QAOA 的对应概率质量为 `39.18%`，因此硬件保留了理想 QAOA 超出随机
  部分的大约 `60.6%`。

这支持“量子采样对代理 QUBO 的候选分布产生正向低能富集”的受限结论。它不
表示能量降低 2.73 倍，也不表示路线缩短 2.73 倍。

端到端路线结果需要单独解释：报告中的 Baihua 在 6/6 个有局部余量的实例上都
产生严格路线改善，平均改善 2.555；但 Random、Simulator、Exact 的平均改善
分别为 2.757、2.888、3.653。Hardware 对 Random 是 3 胜 0 平 3 负，
`p=0.65625`，没有显示显著的路线级优势。

此外，最低 10% 门槛是在首批数据采集后根据评审意见提出，因此当前
`p=0.03125` 应视为探索性证据。门槛现已冻结，仍需要预注册的新硬件批次
进行确认性复现。
